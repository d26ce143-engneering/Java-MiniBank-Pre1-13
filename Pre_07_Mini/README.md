# Practical 7 — MiniBank

Package namespace: `pre07mini` (annotation/exception subpackages are included where needed).

## Open in IntelliJ IDEA
1. Extract the ZIP.
2. Open this `Pre_07_Mini` folder in IntelliJ IDEA.
3. Set Project SDK to JDK 17 or newer.
4. Open `src/pre07mini/MiniBank.java` and click the green Run icon.

## Compile/run from terminal
From this practical folder:

```bash
javac -d out $(find src -name "*.java")
java -cp out pre07mini.MiniBank
```
On Windows PowerShell, compile from IntelliJ using the Run button if the `find` command is unavailable.
